为什么开设此课程？

随着大模型能力的演进，AI正在从简单的“对话框”向具有自主行动能力的Agent（智能体）时代跃迁。国际顶尖闭源大模型公司（如OpenAI，Google，Anthropic）已将Agent视为LLM进化的终极形态——不再仅仅是生成文本，而是通过规划、工具调用和环境交互来解决复杂现实问题。然而，Agent的自主权越高，其安全风险（如指令篡改、越狱攻击）就越致命。因此，掌握“架构能力”与“防御能力”的结合，已成为AI工程师在Agent时代的核心竞争力。

  • Agent架构升级：深度掌握从单一Prompt到复杂Agent状态机（LangGraph）的架构跃迁，构建具备自主规划、工具调用和自我反思能力的智能体。
  • 安全防御前沿：系统学习LLM安全风险（Prompt Injection，Jailbreak）及其防御机制，确保Agent在企业级生产环境中的鲁棒性与安全性。
  • 全链路实战：通过构建“安全增强型多智能体协同系统”等真实项目，实现从架构设计、安全审计到容器化部署的完整交付。
  • 认证凭证：所有参训学员将获得《AI Agent及其安全训练营参加证明》，记录学习模块与实战项目，作为专业进修凭证。

知识与技能模块

Agent核心理论与架构：

  • 推理模式：深度掌握 ReAct (Reasoning and Acting)、Plan-and-Execute 规划模式、Self-Reflection 自省机制。
  • 状态机编排：利用 LangGraph 构建有向图架构，实现循环迭代、条件跳转与复杂状态管理。
  • 记忆系统：实现短期对话上下文管理与基于向量数据库的长期记忆 (Long-term Memory) 检索。

多智能体协同（MAS）：

  • 协作模式：设计角色定义（Persona）、标准化协作协议与分层管理架构。
  • 冲突解决：学习多 Agent 间的共识机制、任务分发与结果聚合算法。

LLM安全风险分析：

  • 攻击向量：深入分析 Prompt Injection（直接/间接注入）、Jailbreak（越狱攻击）、数据泄露与幻觉诱导。
  • 威胁建模：构建 Agent 攻击面分析模型，识别工具调用链中的潜在漏洞。

安全防御与工程化：

  • 防御机制：实施输入净化（Input Sanitization）、输出审计（Output Audit）与NeMo Guardrails动态护栏。
  • 评估体系：使用安全基准测试集进行红蓝对抗评估，量化 Agent 的鲁棒性。
  • 生产级部署：基于 FastAPI 异步框架、Docker 容器化与安全网关的工业级部署方案。
